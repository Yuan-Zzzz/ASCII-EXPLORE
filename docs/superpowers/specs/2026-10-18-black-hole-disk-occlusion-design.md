# 黑洞吸积盘遮挡与成像优先级

日期：2026-10-18  
状态：已与用户确认方向（几何正确 + 真实黑洞式处理）

## 问题

编辑器 / 运行时里，吸积盘远侧会被画进事件视界阴影内部，看起来像「盘在黑洞后面，却渲染到黑洞前面」。上下弯折弧也不连续，尖角、断开，不像连续薄盘被史瓦西透镜弯折后的一次/二次像。

根因：一次射线在冲击参数 `b ≤ b_crit`（临界阴影）时，仍可能与盘面远侧求交；`clears_horizon` 只相对事件视界半径 `rs` 做线段遮挡，而 `b_crit = (√27/2)·rs ≈ 2.598·rs`。因此 `rs ≤ b ≤ b_crit` 的远侧一次像会涂进本应纯黑的影子。

## 目标

在现有薄盘 + Bozza 偏折模型内，按真实黑洞成像习惯处理遮挡与像的优先级：

1. 阴影轮廓内部保持纯黑（除近侧盘真正挡在视线上的前景带）。
2. 远侧盘只以二次偏折像出现在 `b > b_crit` 的上下弧，不进入影子内部。
3. CPU（`BlackHoleOptics`）与 GPU（`black_hole_lens.gdshader`）规则一致。
4. 保留 ASCII / Bayer 呈现；不改为平滑电影渲染色调。

非目标：完整测地线积分、更换光学模型、关掉字符/抖动风格。

## 物理约定（本项目采用的简化）

对观察者发出的每条射线，按下列顺序决定颜色（与常见薄盘黑洞可视化一致）：

1. **近侧一次像**：未偏折射线与盘环带相交，交点在黑洞相对相机的近侧半球，且相机→交点线段不穿入 `r < rs` → 画盘。
2. **捕获 / 阴影**：若冲击参数 `b ≤ b_crit` 且无近侧一次像 → 纯黑（事件视界阴影）。
3. **远侧二次像**：仅当 `b > b_crit` 时，在最近点处按偏折角弯折后再与盘求交 → 画弯折过来的远侧盘（上下弧）。
4. **否则**：背景（含透镜星空）+ 光子环，再叠 `accretion_glow`，最后走 `present()`。

近/远侧判定（明确一种，避免歧义）：

```text
near = dot(hit - center, camera - center) > 0
```

`near == true` 表示交点在「相机所在」一侧的半球（近侧）；否则为远侧。阴影内只允许近侧一次像。

`clears_horizon` 仍相对 `rs` 检查线段最近点；它不替代 `b ≤ b_crit` 的捕获判定。

## 实现落点

| 文件 | 改动 |
|------|------|
| `features/moon_walk/black_hole_lens.gdshader` | 盘命中逻辑按上面 1–4 重排；一次像增加近侧过滤；二次像保持 `b > u_b_crit`；有盘着色前若仅远侧且 `b ≤ u_b_crit` 则不得着色。 |
| `features/moon_walk/black_hole_optics.gd` | `_pick_disk` 与 shader 同一优先级与近侧判定，保证 `trace()` / 测试与画面一致。 |
| `tools/test_black_hole_optics.gd`（及必要时 smoke） | 增加回归：`b ≤ b_crit` 的远侧一次像不得返回盘命中；近侧前景带仍可命中；`b` 略大于 `b_crit` 时二次像仍可命中远侧。 |

不改：`BlackHoleOptics` 的导出参数语义、`present()` / ASCII / Bayer、月面 `DiskLight` 几何（除非 optics 命中变化导致测试断言需同步）。

## 弯折弧连续性（次要、同 PR 内小幅）

在遮挡修对之后，若上下弧仍明显尖角或断开：在**不改变** `deflection_angle` 公式的前提下，只调整二次像求交的取舍（例如偏折角上限与 `b` 接近 `b_crit` 时的稳定），使弧更连续。不做新的光学公式。

## 验证

1. `godot --headless --path . --script res://tools/test_black_hole_optics.gd`（含新遮挡用例）通过。
2. 相关 smoke / light 测试不回归。
3. `shot_black_hole`（或现有拍摄脚本）目视：影子内部无远侧盘色；近侧盘可横过影子前景；远侧呈轮廓外上下弧。

## 成功标准

- 不再出现「远侧盘填进阴影」的深度错误。
- 阴影是干净的圆/临界轮廓，近侧盘与二次弧分层符合上述优先级。
- CPU `trace` 与 GPU 透镜对同一几何约定一致。
