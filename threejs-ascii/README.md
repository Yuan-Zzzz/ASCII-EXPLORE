# ASCII · 月夜篝火

用 Three.js 自写后处理着色器实现的**彩色 ASCII 字符 3D 渲染**小场景：浮空小岛上的月夜，篝火、池塘、树林、随风摆动的草地，以及一个提着灯的小巫师。

## 运行

```bash
npm install
npm run dev       # 开发服务器 http://localhost:5173
npm run build     # 生产构建到 dist/
npm run preview   # 预览构建结果
npm run shot      # （可选）需先 npm run dev；用本机 Chrome 无头截图到 screenshots/
```

`npm run shot` 默认使用 `C:/Program Files/Google/Chrome/Application/chrome.exe`，可用环境变量 `CHROME_PATH` 指定其他浏览器。

```

    GlyphField.js      字符点数据打包、共享材质、attachGlyphs 给网格贴字符
    GlyphRenderer.js   实体深度预渲染 -> 天空 -> 字符点
  core/
    cameraRig.js       等距正交相机，跟随并吸附到字符网格
    input.js           键盘输入与等距方向映射

    trees.js           松树、阔叶树、岩石、原木长凳（含碰撞圆）

    water.js           池塘（波浪法线、月光碎光、火光倒影、涟漪）
```

## 实现要点

- **3D 字符（默认模式，参考 Effulgence RPG）**：字符不锁在屏幕网格上，而是逐个放在模型的特征棱和表面上。棱边上的点按屏幕方向选 `- / | \`，密集排列勾出形状；表面稀疏的点按光照选材质字符。字符始终正对屏幕、固定像素大小，只改变位置和颜色。先把实体网格只写深度渲染一遍，字符再做深度测试，所以背面和被遮挡的字符不会透出来。另外有一层屏幕空间最小间距（F 键开关）：先把每个字符点画成圆盘写入低分辨率缓冲（表面字符直径等于字符宽，棱边字符只有一半，轮廓可以更密），重叠处棱边优先、近处优先，正式渲染时被占掉的字符直接丢弃，远处挤在一起的字符不再糊成一团。
- **限定调色板**：字符没有背景色块，统一画在夜色底上，字色只取自约 18 色的调色板；被火光照亮的字符换成暖色梯度。字符边缘用 4x4 Bayer 抖动决定画或不画。
- **动态**：草叶/树木在顶点着色器中摆动，阵风波掠过草地时草尖泛光；角色经过时草被推开，靠近水面产生涟漪；火焰与火星全在 GPU 端按时间计算。角色朝向按等分角度逐档转动。
- **等距相机**：正交相机 45°/35.26°，平滑跟随。T 键可以切回原始模型，方便对照字符是从哪套几何上取的。
